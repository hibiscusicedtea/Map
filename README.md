# Parkside Downtown + Harbourfront Map

This version keeps the original Parkside visual style and uses the updated downtown–Harbourfront GeoJSON. The map is shown in a selected location’s details panel, with nearby category pins within 2 km.

## Open the site

1. Unzip this folder.
2. Open the `parkside_downtown_map` folder in VS Code.
3. Start `index.html` with Live Server. The GeoJSON is already in `data/parks.geojson`.
4. Select a location card to open its map. Use the amenity chips to turn nearby pin categories on or off.

The data contains 82 locations. A blank amenity list means the source file did not list an amenity for that location; the site labels it “No amenity listed.” The map style and marker design follow the supplied Parkside files.
